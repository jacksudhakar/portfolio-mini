# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project is designed to showcase my skills, projects, experience, and interests in web development.

## 🚀 About the Project

This portfolio website was created using **HTML and CSS** with a clean, simple, and responsive design. It provides an overview of my work and gives visitors an easy way to learn more about me and my development journey.

## 🛠️ Technologies Used

- **HTML5** – For the structure and content of the website
- **CSS3** – For styling, layout, animations, and responsive design

## ✨ Features

- Responsive and user-friendly design
- About Me section
- Skills section
- Projects showcase
- Contact section
- Clean and modern UI
- Works across different screen sizes
